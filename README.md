# 高中语文古诗文 · Vela 快应用

基于项目原有的 Vela `.ux` 模板开发。内容按用户提供的《高中统编版语文古诗文大全 (1).docx》整理，包含 5 册、68 篇、204 个原文/翻译/注释分区，全部随安装包离线提供。

## 页面与返回

1. 书本列表：必修上册、必修下册、选择性必修上册、中册、下册。
2. 篇目列表：按 Word 目录的篇目顺序展示。
3. 内容选择：“原文”“翻译”“注释”三个选项。
4. 正文阅读：保留原文分行、段落和注释，长段分块显示。

右滑每次只返回一级：正文 → 内容选择 → 篇目列表 → 书本列表 → 桌面。
书本列表是第一级页面，右滑调用系统返回并回到桌面，重复手势不会重复退出。纵向滑动只滚动内容。
四个页面的纵向滚动区域均启用原生 `bounces`，滑到列表或正文底部后继续拖动并松手会产生回弹。

## 开发与构建

需要 Node.js 18 或以上版本。在 AIoT-IDE 中打开本项目后可使用 Vela 模拟器调试。

```sh
npm install
npm test
npm run build
npm run start
```

调试安装包：`dist/com.gaozhong.chinese.poetry.debug.1.0.0.rpk`。
可通过 AIoT-IDE 安装到模拟器或连接的设备。`npm run build` 完成后会自动校验安装包中的页面、样式和全部正文资源。

应用包名为 `com.gaozhong.chinese.poetry`，应用显示名称为“高中人教版语文古诗词”。`prebuild`/`prestart` 会清理生成目录，避免修改包名后误用旧 RPK 或混合 manifest；包内 manifest、启动配置和 RPK 文件名由 `npm run build` 统一校验。

`npm run release` 用于发布构建；正式发布前应配置自己的签名，不能把工具链的默认调试签名用于正式发布。

## 内容与样式

- `src/data/catalog.json`：五册教材的篇名、作者和稳定 ID。
- `src/common/texts/`：204 份按篇、按分区保存的 UTF-8 JSON 文本，使用 `.txt` 扩展名以兼容 Vela 资源读取。
- 各页面的 `<style>`：直接保存《设计语言规范.docx》的完整 CSS，只将缩进中的不换行空格转换为普通空格。
- `src/common/design.css`：相同样式的校验副本，页面不再通过 `@import` 引入。
- `src/common/navigation.js`：页面跳转与只退一级的右滑手势。

四个页面的 `<style>` 均与文档提取的 CSS 一致，没有附加样式覆盖。界面使用 `designWidth: 480`，复用文档的屏幕媒体查询。正文使用本地文件 API 按需加载，不一次载入整本教材。程序不自动补写、删改或校订文档内容；界面的“翻译”对应文档中的“【译文】”。

## 重新导入与校验

默认读取当前用户下载目录中的古诗文文档，以及桌面上的设计规范文档：

```sh
npm run import:docs
npm run check:source
npm run check:package
```

也可指定文件位置：

```sh
npm run import:docs -- --poetry "路径/古诗文.docx" --design "路径/设计语言规范.docx"
```

导入工具在 Windows 上使用 PowerShell 的 ZIP/XML 解析器读取 Word，不需要安装 Word 或 Python。它会检查五册数量、全部篇名/作者、204 个分区及分区顺序，并生成 `tests/fixtures/source-index.json` 中的段落数量、字符数量和 SHA-256 校验记录。

`npm test` 覆盖内容完整性、全部阅读入口、长段无损拆分、逐级返回、首页右滑退出、滚动不误退、无效参数、读取失败重试和离开页面后的异步回调。

## 方屏测试

已在 Vela 原生模拟器的 480×480 正方形屏幕及 336×480 方屏上检查书本、篇目、原文、翻译、注释和逐级右滑返回，未添加任何样式覆盖。首页右滑会退回桌面，纵向滑动可以正常滚动列表和正文。

已检查最长篇名的换行，并将《孔雀东南飞并序》的 409 段注释及 4145 字符译文滚动到末尾，与源文档末句核对一致。自动测试遍历全部 204 个阅读入口，并校验所有文本；原生模拟器使用代表性篇目做交互和显示检查。尚未连接实体手表或手环测试。
